These paths are already declared in the project frontmatter. Match the filename and it
appears automatically on the next build. Change the frontmatter if you prefer different
names.

Guidelines:
- JPG or PNG, around 1600px wide
- Landscape crops fit the layout best
- `hero.jpg` is the large image at the top of a project page
- Photos of you working on the hardware are worth including; they make the work concrete
- Before publishing propulsion photos, check with HSP leadership on export control
